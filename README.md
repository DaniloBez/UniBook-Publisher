# UniBook Publisher
Модульна платформа для автоматизації видавничих процесів: супровід життєвого циклу рукописів від подання автором до поглавної редактури, дизайну, фінансового контрактування та пакетного нарахування роялті.

## Архітектура та моду
Проєкт реалізовано за концепцією модульного моноліту на базі Spring Modulith. Домени суворо ізольовані та взаємодіють між собою за допомогою подій.

```
src/main/java/com/unibook/publisher/
├── identity/          # Автентифікація, ролі, профілі користувачів
├── production/        # Життєвий цикл рукописів, розділи, версіонування та правки
├── finance/           # Контракти, фіксація продажів, розрахунок роялті
└── communication/     # Системні in-app сповіщення, локалізовані email-повідомлення
```

## Технологічний стек
 - Мова та платформа: Java 25, Spring Boot 4.1.1
 - Модульність та події: Spring Modulith  
 - Безпека: Spring Security  
 - Робота з даними: Spring Data JPA, H2 Database (dev/test), PostgreSQL (production)  
 - Зберігання файлів: S3 (для рукописів та обкладинок)  
 - Шаблонізація: Thymeleaf
 - Збірка та CI: Gradle Wrapper, GitHub Actions

## Локальний запуск та тестування
### Передумови
 - Встановлена JDK 25
 - Git

### Кроки для запуску
1. Клонувати репозиторій:
```bash
git clone https://github.com/DaniloBez/UniBook-Publisher.git
cd publisher
```

2. Запустити перевірку архітектури та юніт-тести:
```bash
./gradlew test
```

3. Запустити застосунок локально (профіль dev за замовчуванням використовує H2 в пам'яті):
```bash
./gradlew bootRun
```

4. Доступ до локальних ресурсів:
   - Web-застосунок: http://localhost:8080
   - H2 Console: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:unibook_db)
